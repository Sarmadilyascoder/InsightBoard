Method note

Built on an open, cited data source.

Every figure is requested directly from the World Bank Indicators API when you open or refresh the dashboard. The country directory is also provided by the World Bank, so you can search the available countries by name or three-letter code. Different indicators can have different latest reporting years, so InsightBoard always shows the observed year beside each value.
